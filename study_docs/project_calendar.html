Why the environment has one owner: Juan's physics background suits the inner PD controller, and one designer keeps it consistent. Env v1 is merged, so it is now fixed: changes to the action layout, reward weights or levels go through Juan and get announced, otherwise the three-way comparison stops being fair. Shared: each writes the report section for their own algorithm, and everyone must be able to explain all three at the oral defence (25 pts, individually assessed), hence two cross-teaching sessions. Roles are a proposal: swap freely, and use one branch per person so contributions are visible in git.
